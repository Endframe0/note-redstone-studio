# AI音频扒谱：从音频到红石投影

音符工坊 2.12.3 支持 MP3、WAV、FLAC、OGG 等音频。先由 MuScriptor 识别音符，再复用已有 MIDI 节拍适配和红石布局引擎。纯原版为默认制作版本，ENB 仍由你自行选择。

按文件实际内容解码，而不只依赖扩展名。中文路径使用文件句柄读取；遇到 AAC、M4A／MP4 或扩展名写错的媒体时，通过独立运行库中的 FFmpeg 提取音轨。文件中没有音轨时会明确提示；不修改原始文件。

## 首次使用

1. 选择音频，打开「AI音频扒谱」。默认模型为 **Small**，默认设备为「自动（优先 NVIDIA GPU）」。
2. 点击「准备所选模型」。首次安装独立 Python、PyTorch 和 MuScriptor 运行库，需要联网及数 GB 空间；组件目录可以改到空间充足的磁盘。它们不进入转换器自身的 Python 环境。
3. Small 随便携包提供本地权重时直接读取，不需要 Hugging Face 登录。使用下载入口时，需要先在所选模型页面接受授权，再用读取令牌登录；令牌由 Hugging Face 的本机缓存管理，不写入转换器设置。
4. 选择纯原版及「原版智能八度（保留音级）」，开始转换。转录阶段和搜索阶段都能取消。

GPU 优先会实际检查 CUDA 和显卡分配。不可用时使用 CPU；转录途中遇到 CUDA 或显存错误会清理显存、在 CPU 上重试一次。也可手动选「仅 CPU」。此选项只控制音频识别，与红石布局搜索的 CPU / GPU 选项分开。

模型下载需要访问 Hugging Face 及其文件服务。每个受限模型先在对应网页接受授权，再在软件里登录读取令牌。直连超时时，可配置能访问这些服务的代理后重新打开转换器；下载子进程继承启动时的 `HTTP_PROXY` / `HTTPS_PROXY` 环境变量，目前没有独立代理输入框。也可以通过浏览器下载模型文件，再用「选择本地模型」加载，后续无需重复下载。

## Medium、Large 自行安装

软件只提供模型接口，不附带 Medium 或 Large 权重，也不会提前下载它们。

| 模型 | 用途 | 官方页面 |
| --- | --- | --- |
| Small-0.1b-默认-低级 | 默认，约 0.1B 参数，随包提供 | [Small](https://huggingface.co/MuScriptor/muscriptor-small) |
| Medium-0.3b-1.5G显存-中级(手动下载) | 约 0.3B 参数，手动下载 | [Medium](https://huggingface.co/MuScriptor/muscriptor-medium) |
| Large-1.4b-6.1G显存-高级(手动下载) | 约 1.4B 参数，手动下载 | [Large](https://huggingface.co/MuScriptor/muscriptor-large) |

界面显存数字为参考值，实际占用以运行情况为准。Small 默认采用原始 FP32 权重，CUDA 下使用 FP16 混合精度计算；未使用 INT8 / INT4 权重量化。

在对应页面授权，下载 `model.safetensors` 与 `config.json` 到同一文件夹。在软件选择相应模型，再用「选择本地模型」指定该目录。也可以留空本地目录，主动点击「准备所选模型」下载到组件缓存；各模型授权与缓存独立。只选择模型不会开始下载。Medium / Large 目前只验证了选择与连接逻辑，未做本机完整神经转录测试，实际显存占用与耗时需试用确认。

## 纯原版的音域适配

「原版智能八度」先按源音轨、通道、GM 乐器分部选择整体八度，让更多音符落进原版两八度范围；再对剩余越界音符折叠。能容纳的旋律尽量保留内部音程，宽于两八度的分部仍会改变部分旋律走向。报告记录每部分移调及折叠数量，不改变音级、乐器映射或起音。

严格保留、普通八度折叠仍可选。智能八度仅用于纯原版 MIDI；NBS 与 ENB 不套用此调整。新配置默认使用智能八度；已有配置保持原选择。原版音符盒仍不支持独立持续时间、音量力度或包络。

## 输出与缓存

原始转录 MIDI、转录说明保存在输出目录的 `音频转录` 子目录，然后另行生成投影。缓存按音频内容、模型权重与转录参数匹配；调整 Minecraft 版本、原版音域或布局时可以复用转录。原音频不上传到转录服务。

MuScriptor 识别音高、起止时间和乐器，不识别逐音符力度或动态控制器，输出力度统一为 100。不会把这些值说成从 MP3 恢复的真实力度。复杂混音可能出现错音、漏音、分部错误；达到解码预算时会记录警告。Small 转录后应先试听 MIDI，再检查投影。

转录阶段不额外贴网格、不自动补长音符；10t / 20t 与允许变速由转换器统一适配。默认低误差时优先紧凑 10t，密集快音保留 20t；在「MIDI 时长与节拍 → 时序与体积」可改为精度优先或固定档位。Beat This 节拍模型随便携包提供，按文件大小与 SHA-256 校验后放入独立缓存；缺失时才从官方地址下载。Windows 音频子进程使用系统原生证书校验，避免 Python 选中过期的交叉签名证书。网络失败或节拍不明确时，会明确使用绝对时间、120 BPM 占位速度，不能把占位值当作识别出的 BPM。游戏刻仍可能需要量化，误差会报告。
