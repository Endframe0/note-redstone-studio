# MIDI 直接转换

选择 `.mid` 或 `.midi` 文件即可分析，不必先转换成 NBS。支持 Standard MIDI File Format 0 / 1、PPQ 时基；Format 2 和 SMPTE 时基会明确提示。

![MIDI 时长与节拍设置，毛玻璃界面](images/midi.png)

## 先选纯原版或模组版

自动配置只自动处理节拍与布局。**制作版本必须由你选择**，不会根据音域或力度自行切换。上次选择会保存。

- **纯原版音符盒**：MIDI 也可以直接生成原版红石投影，不需要 ENB。保留乐器映射、音高和起音；音域只有两八度，不能独立保留 Note Off 时长、淡入淡出或力度。超出音域时默认提示，你可选择「八度折叠 / 半音取整」，折叠数量会记录。
- **ENB 模组音符盒**：支持下述持续时间、力度及渐变，需要配套 26.x ENB。

## 模组版的时长、力度与音色

- Note On / Note Off 决定持续时间，识别 CC64 延音踏板及同音重叠，跨速度变化计算时长。
- 手动模式将 MIDI Note On 与起音瞬间 CC7、CC11 相乘写入 ENB；自适应模式保留原始力度，并通过独立曲线应用动态控制器。默认 GM 通道音量为 100/127。
- 乐器与八度、10 通道打击乐按 [Open Note Block Studio 映射表](https://github.com/OpenNBS/NoteBlockStudio/blob/79b22ad890631a39196d45b9c27881599f9b04ab/scripts/midi_instruments/midi_instruments.gml) 转成 Minecraft 音符盒音色。并非重现原 MIDI 合成器的 GM 音源。
- MIDI 没有通用的淡入淡出时值字段。新配置默认使用自适应包络。手动统一模式初始淡入 **0 ms**、淡出 **50 ms**；在音乐文件下方展开「MIDI 时长与节拍」可改为 0–20000 ms，或关闭淡入淡出。
- 持续时间与包络以 **50 ms 游戏刻**写入；最短持续 1 游戏刻。手动统一模式的两段渐变限制在音符时长内；自适应模式的释放尾音追加在松键 / 踏板释放之后；已衰减至低音量的尾音可提前结束。
- 使用延音的 ENB 音符盒设置 `oneShot=false`、`holdUntilRelease=false`，红石短脉冲的下降沿不会提前停止声音。沙子底座小鼓例外：始终 `oneShot=true`，不使用 MIDI 时长、统一淡入淡出或自适应曲线，保留起音时的力度与音高。仍使用 ENB 保存音高和力度，声音按原版采样自然结束。NBS 文件继续保留原来的自然尾音模式。
- **26.x ENB port.3 支持相位对齐延音。**按时长播放时保留起音，从周期采样重建稳定延音，减少循环接缝造成的音量起伏；非周期打击音保留片段循环，直至设定的结束时刻；淡入淡出继续按游戏刻控制。原版短采样延长后属于合成延音，音色可能不同于真实乐器长音。NBS 一次性音符保持自然播放。请同时更新客户端和服务端模组；旧 port.1 不具备这项能力。

纯原版 MIDI 导出沿用 1.20～26.3 的目标版本支持。MIDI 的 **ENB 时长与包络模式**使用配套 **26.1 / 26.1.1 / 26.1.2 / 26.2 / 26.3 ENB 移植版**。1.20.1 / 1.21.1 的现有补丁只走一次性声音通道，选择 ENB 时会拦截并提示选择 26.x 或改选纯原版，不会输出失效的包络。NBS 旧版兼容不变。

## 26.1+ 铜管音色

目标版本为 26.1 或更新版本时，在 OpenNBS 基础映射上启用本项目的铜管映射。原版与 ENB 两种制作版本均适用，NBS 中已有的铜管乐器保持原样。低版本继续使用 OpenNBS 兼容音色，不生成不存在的乐器。

| MIDI GM 乐器（编号从 1 开始） | 游戏音色 |
| --- | --- |
| 57 小号、62 铜管组、63 合成铜管 1 | 铜块小号 `trumpet` |
| 58 长号 | 锈蚀铜块 `trumpet_weathered` |
| 59 大号 | 氧化铜块 `trumpet_oxidized` |
| 60 弱音小号、61 圆号、64 合成铜管 2 | 斑驳铜块 `trumpet_exposed` |

这是对 GM 乐器的近似分配，不是四套完整管弦音源；弦乐等其余音色继续参考 OpenNBS。锈蚀和氧化铜块采样的基准比另两种低一个八度，导入时补偿 +12 半音，再应用所选音域限制。普通结构使用涂蜡铜块底座，避免氧化改变音色。

新增的四种音色见 [Minecraft 26.1 官方更新说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1)。`转换报告.json` 的 `midi.mappingProfile` 和 `copperMappedNotes` 记录本次映射方式及铜管音符数。

## 10t、20t 与 BPM

默认「紧凑优先」：先比较 10t / 20t 的整曲时序，再检查 10t 对独立起音与全部音符的影响。在误差很小时优先 10t，避免几个偏移音符导致整首增加一套奇偶分相线路。密集快音仍保留 20t。不会删除音符或逐间隔累加取整；所有速度段共用一个整体变速比例。

紧凑门槛同时检查独立起音与音符数量：独立起音均方根误差不超过 10 ms（或比最佳 20t 多不超过 3 ms）；超过 25 ms 的起音和音符均不超过各自的 2%；新增起音合并不超过 0.5%。这是一组工程阈值，不等于主观听感保证；最大误差、合并数量及两档对比会写入报告。严格原速仍不能引入量化。

「时序与体积」另有精度优先、固定 10t 和固定 20t。精度优先沿用最小化整曲时序误差的策略；固定档位仍受所选变速与严格规则约束。手动选择会随配置保存。

必须使用 20t 时，奇偶相位按真实方块、电气隔离、音符顶部空气和沙子承托检查间距，尝试紧贴及错层嵌入，不再固定预留沙子空层。外部错拍启动器仍单独统计。

| 选项 | 行为 |
| --- | --- |
| 节拍适配（默认） | 在允许幅度内整体调整 BPM，所有速度段使用同一倍率，默认最多 ±10%；优先保留起音相对拍点 |
| 保持原速（允许量化） | 不调整 BPM，在绝对时间轴量化起音 |
| 严格原速（不可量化） | 不调速、不量化；无法整刻表示时明确停止 |

例如 119 BPM 的八分音符可适配为 120 BPM / 20t，每个八分音符间隔 5 游戏刻；长段演奏不因逐间隔取整累积漂移。120 BPM 的十六分音符则需要 2.5 游戏刻，不能在小幅变速内全部整刻表示；默认选择 20t 并明确显示至多 25 ms 的量化偏差。

变速曲保留原 MIDI tempo map 的各段比例，整首只使用一个速度倍率，不单独改变某段 BPM。分析区和报告记录每段原 BPM、实际 BPM、调速百分比、起音最大误差及合并起音数。有量化的结果不会标为严格对齐；会分别显示精确对齐与仍需量化的音符数量、平均 / 最大偏差和不同起音合并数。速度调整不改变音高。

例如测试的《七里香》MIDI（7714 个音符，原速约 72 BPM），紧凑优先选择 75 BPM / 10t；只在少数偏移起音处近似，全部 7714 个音符保留。精度优先仍可选择 75 BPM / 20t。具体误差记录在转换报告中，不标成全曲精确对齐。

## 文件兼容

完整音轨之后的零填充，以及与最后音轨结尾完全一致的重复尾部，可以兼容读取并明确提示字节数；不修改源文件。不能确认含义的尾部仍会报错，避免把额外音轨当作垃圾数据丢弃。

## 当前边界

不还原弯音曲线、声像、效果器及 SysEx；检测到相关事件会提示。演奏过程中的 CC7/11 音量变化仅由自适应包络模式读取。未映射的打击乐使用小鼓近似并提示。缺少 Note Off 的声音持续到文件结尾并提示。超过 ENB 音域的映射音高需手动移调或八度折叠。

导出报告的 `midi` 字段包含适配数据，`扩展音符盒配置.json` 列出每块音符盒的持续时间与渐变。乐句复用会比较持续时间及渐变，避免长短不同的音符错误共享同一配置。生成结果仍需在目标 Minecraft 实例试听；文件回读不等于整曲声音验收。


## MIDI 自适应包络（2.11.4）

在“MIDI 时长与节拍 → 音量包络”选择 **MIDI 自适应包络**。新配置默认使用该模式；已有手动选择保留。

- 每个音符独立写入 ENB 的 `AdvancedData.VolumePoints`，原始起音力度与动态 CC7 音量、CC11 表情只相乘一次。起音时表情为零、随后渐强的音符也会保留。
- Note Off / CC64 踏板释放决定常规释放段起点。尾音接在其后，不改变后续音符的起音；允许自然重叠。
- 最终衰减尾音的包络增益严格低于 **0.11** 后，在最多 **5 游戏刻（250 ms）**内平滑归零并结束播放；原来的尾音更短时不会延长。阈值应用于独立曲线、在乘以音符力度之前，不是总混音响度。起音淡入、稳定的轻音和 MIDI 后续渐强会保留。长按 / 踏板保持的钢琴等衰减音色可在 Note Off 前自然收尾。手动统一模式及 NBS 自然尾音不应用这项规则。沙子底座小鼓不使用任何 MIDI 包络，直接播放自然尾音。
- CC72、CC73、CC75 分别相对调整乐器预设的释放、起音、衰减。控制值不是毫秒；这是兼容近似，无法恢复未知音源的原始 ADSR。
- GM 铜管、木管及簧片类（20–23、56–79，零起始编号）读取 CC2 呼吸控制并近似为音量变化。其他乐器不强行应用 CC2。缺失数据按钢琴、拨弦、管乐、弦乐、Pad 等预设推算。
- 以 50 ms 游戏刻取样后简化曲线，绝对增益误差阈值为 0.001。当前不还原呼吸控制对滤波器的影响、松键力度映射、混响、合成器专属控制或原音源音色。
- 复用匹配包含曲线，因此相同音高但包络不同的音符不会误用同一方块；可能降低复用率。

“按设置淡入淡出”保留之前的统一毫秒设置，渐变限制在音符时长内；“不使用淡入淡出”仍保留 Note Off 时长。自适应模式忽略手动毫秒值，切回手动后原数值仍在。纯原版不应用这些包络。

生成报告记录独立曲线数量、低音量收尾数量、CC2 近似应用数量和 CC72 / 乐器推算来源；配套 port.3 已支持读取曲线，无需新增模组。已有投影要使用自适应包络，需要重新转换。

本次便携包附带 **26.x ENB port.4**，另修复单音试听忽略 `oneShot`、强制按 20 刻延音的问题。试听与红石激活现在共用播放设置。NBS 自然播放在界面显示“原版自然尾音”，不再把未使用的 40 刻占位值当作有效时长；MIDI 的独立包络仍按时长播放。更新模组需重启 Minecraft；这一试听修复不需要重建旧 NBS 投影。超出原版音域时，变速采样本身仍会改变尾音长度，不代表正在循环。已通过后台音频与数据测试，当前存档的红石播放主观问题仍需实机复核。
