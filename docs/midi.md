# MIDI 直接转换

选择 `.mid` 或 `.midi` 文件即可分析，不必先转换成 NBS。支持 Standard MIDI File Format 0 / 1、PPQ 时基；Format 2 和 SMPTE 时基会明确提示。

![MIDI 时长与节拍设置，毛玻璃界面](images/midi.png)

## 先选纯原版或模组版

自动配置只自动处理节拍与布局。**制作版本必须由你选择**，不会根据音域或力度自行切换。上次选择会保存。

- **纯原版音符盒**：MIDI 也可以直接生成原版红石投影，不需要 ENB。保留乐器映射、音高和起音；音域只有两八度，不能独立保留 Note Off 时长、淡入淡出或力度。超出音域时默认提示，你可选择「八度折叠 / 半音取整」，折叠数量会记录。
- **ENB 模组音符盒**：支持下述持续时间、力度及渐变，需要配套 26.x ENB。

## 模组版的时长、力度与音色

- Note On / Note Off 决定持续时间，识别 CC64 延音踏板及同音重叠，跨速度变化计算时长。
- 力度由 MIDI Note On、起音瞬间 CC7 音量和 CC11 表情相乘，写入 ENB 0–127。默认 GM 通道音量为 100/127。
- 乐器与八度、10 通道打击乐按 [Open Note Block Studio 映射表](https://github.com/OpenNBS/NoteBlockStudio/blob/79b22ad890631a39196d45b9c27881599f9b04ab/scripts/midi_instruments/midi_instruments.gml) 转成 Minecraft 音符盒音色。并非重现原 MIDI 合成器的 GM 音源。
- MIDI 没有通用的淡入淡出时值字段。默认淡入 **0 ms**、淡出 **50 ms**；在音乐文件下方展开「MIDI 时长与节拍」可改为 0–20000 ms，或关闭淡入淡出。
- 持续时间与包络以 **50 ms 游戏刻**写入；最短持续 1 游戏刻。两段渐变限制在音符时长内，短音自动缩短渐变，不额外拉长尾音。
- ENB 设置 `oneShot=false`、`holdUntilRelease=false`，红石短脉冲的下降沿不会提前停止声音。NBS 文件继续保留原来的自然尾音模式。
- **26.x ENB port.2 支持延音循环。**按时长播放时保留起音、循环采样片段并平滑衔接，直至设定的结束时刻；淡入淡出继续按游戏刻控制。原版短采样延长后属于合成延音，音色可能不同于真实乐器长音。NBS 一次性音符保持自然播放。请同时更新客户端和服务端模组；旧 port.1 不具备这项能力。

纯原版 MIDI 导出沿用 1.20～26.3 的目标版本支持。MIDI 的 **ENB 时长与包络模式**使用配套 **26.1 / 26.1.1 / 26.1.2 / 26.2 / 26.3 ENB 移植版**。1.20.1 / 1.21.1 的现有补丁只走一次性声音通道，选择 ENB 时会拦截并提示选择 26.x 或改选纯原版，不会输出失效的包络。NBS 旧版兼容不变。

## 26.1+ 铜管音色

目标版本为 26.1 或更新版本时，在 OpenNBS 基础映射上启用本项目的铜管映射。原版与 ENB 两种制作版本均适用，NBS 中已有的铜管乐器保持原样。低版本继续使用 OpenNBS 兼容音色，不生成不存在的乐器。

| MIDI GM 乐器（编号从 1 开始） | 游戏音色 |
| --- | --- |
| 57 小号、62 铜管组、63 合成铜管 1 | 铜块小号 `trumpet` |
| 58 长号 | 锈蚀铜块 `trumpet_weathered` |
| 59 大号 | 氧化铜块 `trumpet_oxidized` |
| 60 弱音小号、61 圆号、64 合成铜管 2 | 斑驳铜块 `trumpet_exposed` |

这是对 GM 乐器的近似分配，不是四套完整管弦音源；弦乐等其余音色继续参考 OpenNBS。锈蚀和氧化铜块采样的基准比另两种低一个八度，导入时补偿 +12 半音，再应用所选音域限制。普通结构使用涂蜡铜块底座，避免氧化改变音色。

新增的四种音色见 [Minecraft 26.1 官方更新说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1)。`转换报告.json` 的 `midi.mappingProfile` 和 `copperMappedNotes` 记录本次映射方式及铜管音符数。

## 10t、20t 与 BPM

自动比较 10t 和 20t，优先选择能对齐全部起音与变速边界、速度调整较小的方案。同一速度段使用统一拍长，**不把每个间隔各自取整后累加**。

| 选项 | 行为 |
| --- | --- |
| 节拍适配（默认） | 在允许幅度内整体调整 BPM，所有速度段使用同一倍率，默认最多 ±10%；优先保留起音相对拍点 |
| 保持原速（允许量化） | 不调整 BPM，在绝对时间轴量化起音 |
| 严格原速（不可量化） | 不调速、不量化；无法整刻表示时明确停止 |

例如 119 BPM 的八分音符可适配为 120 BPM / 20t，每个八分音符间隔 5 游戏刻；长段演奏不因逐间隔取整累积漂移。120 BPM 的十六分音符则需要 2.5 游戏刻，不能在小幅变速内全部整刻表示；默认选择 20t 并明确显示至多 25 ms 的量化偏差。

变速曲保留原 MIDI tempo map 的各段比例，整首只使用一个速度倍率，不单独改变某段 BPM。分析区和报告记录每段原 BPM、实际 BPM、调速百分比、起音最大误差及合并起音数。有量化的结果不会标为严格对齐；速度调整不改变音高。

## 文件兼容

完整音轨之后的零填充，以及与最后音轨结尾完全一致的重复尾部，可以兼容读取并明确提示字节数；不修改源文件。不能确认含义的尾部仍会报错，避免把额外音轨当作垃圾数据丢弃。

## 当前边界

不还原弯音曲线、声像、效果器、SysEx 和演奏过程中的 CC7/11 包络；检测到相关事件会提示。未映射的打击乐使用小鼓近似并提示。缺少 Note Off 的声音持续到文件结尾并提示。超过 ENB 音域的映射音高需手动移调或八度折叠。

导出报告的 `midi` 字段包含适配数据，`扩展音符盒配置.json` 列出每块音符盒的持续时间与渐变。乐句复用会比较持续时间及渐变，避免长短不同的音符错误共享同一配置。生成结果仍需在目标 Minecraft 实例试听；文件回读不等于整曲声音验收。
