# NBS 红石投影转换器 2.10.0 · 版本兼容说明

在“转换方式”中先选择版本范围，再选择实际游戏版本。手动配置中的 Java 版本也按范围分组。范围是筛选条件，导出仍针对具体版本，不代表一份投影可以随意降级使用。版本会随上次设置和五个配置槽保存。

## 纯原版投影

支持选择 1.20、1.20.1～1.20.6、1.21、1.21.1～1.21.11、26.1、26.1.1、26.1.2、26.2、26.3，共 24 个正式版本；不包含快照与预发布版。

- 按 Mojang 官方版本数据写入 MinecraftDataVersion。1.20～1.20.4 使用投影格式 v6，1.20.5 起使用 v7，漏斗物品 NBT 同步切换 Count/count 格式。
- 普通布线、沙子独立音轨、层间压缩及 10t/20t 输出按目标版本生成。20t 仍使用实体红石奇偶分相电路，启动器不计主体包围盒。
- 沉重核心、铜灯乐句复用需要 1.21 或更新版本；旧版明确限制，不会生成不存在的方块。铜管音色需要 26.1 或更新版本。
- 毒曲保留 100×100 截面限制、无限长方向和命令方块跟随。命令方块需要游戏权限。
- Quinn v1.3 仍仅开放原来已适配的 26.1.2，不能把数据包直接视为全版本通用。

“纯原版”指播放结构不依赖音域模组。查看和粘贴 .litematic 仍需要与游戏版本匹配的 Litematica/MaLiLib；若手工按投影搭建，原版音符盒需要调音。ENB 则必须完整粘贴方块实体 NBT。

## ENB 配套模组

打开便携包的“配套模组/具体版本”文件夹。只使用一个目标版本目录内的 JAR，不要把所有版本一起复制到 mods。

| 游戏版本 | 安装组合 |
|---|---|
| 1.20.1 | 官方 ENB 1.9.1 + enb-nbs-compat 1.0.0 + 对应 Fabric API |
| 1.21.1 | 官方 ENB 1.9.1 + enb-nbs-compat 1.0.0 + 对应 Fabric API |
| 26.1、26.1.1、26.1.2、26.2、26.3 | 对应版本的 ENB 移植版 + 对应 Fabric API |
| 其余已列出的正式版本 | 可导出原版投影；本包没有对应 ENB 组合，需要 ENB 的歌曲会明确提示更换目标版本 |

需要 Fabric Loader；本次验证使用 0.19.3。单人安装在客户端，联机时客户端与服务器都需要匹配组合。程序不会改动现有游戏目录或自动安装模组。

低版本保留官方 ENB 原始 JAR，并附来源与 SHA512。小型兼容补丁识别转换器的 vanillaInstrument 字段，使用原版声音、MIDI 相对音高和 velocity 力度进行自然一次性播放；没有该字段的普通 ENB 方块维持上游逻辑。不能省略补丁，否则原版音色标记会被上游忽略。

所有 ENB 组合继续保留 NBS 音符力度 × 音轨音量，换算到 0～127。音高为 NBS key + 21；ENB 可表示 MIDI 0～127，NBS 文件本身仍按其格式校验，超出源文件键域的高低音可用移调设置。微分音、自定义采样和声像不因这次版本扩展而自动获得支持。

Java 要求：1.20～1.20.4 为 Java 17；1.20.5～1.21.11 为 Java 21；26.x 为 Java 25。建议由启动器管理对应 Java。音频通道扩容、等响度、Replay、光影属于独立模组，本次配套更新的是 ENB，不表示其他模组也已全版本移植。

## 已完成的验证及边界

- 24 版本的普通/长结构写入、10t/20t 投影、漏斗 NBT 格式；76 份投影由独立 NBT 读取器回读。
- 1.20、1.20.5、1.21.1、26.3 的实际布局搜索与导出。
- 七组 ENB 目标的全 128 个 MIDI 值、16 种共同音色及力度导出；实际 20t 毒曲小样转换。
- 1.20.1、1.21.1、26.1、26.1.1、26.2、26.3 的独立服务端测试：奇偶启动器连续三次相差 1 游戏刻，ENB 音高 0/60/127、力度 63、NBT 保存及供电/断电。26.1.2 沿用已有验证版。
- 各新增 ENB 组合的客户端 Mixin 转换检查：在创建游戏窗口前退出，未占用前台。
- 桌面版本范围切换、配置保存、真实转换、取消、导出当前最优、预览及隐藏窗口截图检查。

新增版本没有逐曲实机试听，也没有在全部 24 个客户端版本中逐一粘贴整机。客户端注入检查不是音频听感验收。使用新目标版本时，先用自己的短片段验证，再转换大型音乐；转换报告会保留验证范围提示。
