# NBS 红石投影转换器 2.10.0

新版桌面工作台。解压整个文件夹，再打开「NBS红石投影转换器2.10.0.exe」。不要只复制 exe。

## 主题与动态效果

- 浅色「纸间」使用中性灰白底、压印控件、虚线文件卡和实体层叠预览。
- 深色「夜航」使用黑灰面板、蓝色图标和线条、边缘高亮及独立仪表读数。
- 毛玻璃「浮光」使用独立的悬浮侧栏、预览岛与操作条，搭配蓝紫透光、柔和高光和半透明卡片。Windows 11 支持时启用系统 Acrylic；其他环境使用渐变玻璃底色。
- 首次启动默认「浮光」，之后恢复上次使用的主题。
- 右上角按钮显示当前主题名称（纸间、夜航、浮光），点击可切换主题。动态效果尊重 Windows 的减少动画偏好。
- 读取与搜索使用 Rose Four 曲线动画。动画表示仍在工作，不代表完成百分比。
- 设置和主题自动保存。原来的默认配置、五个可命名配置槽及上次设置继续使用。
- 窗口按钮紧贴顶部和右边缘，任务栏图标支持最小化与恢复。原生标题栏改为自绘窗口栏；拖动顶部整条区域（按钮除外）移动窗口，双击最大化/还原。右上角可最小化、最大化和关闭，窗口边缘可拖动调整尺寸。
- 程序、窗口与任务栏统一使用新的红石工坊图标。

主题菜单 →「界面字号」可选择 90%、100%、110%、120%、130%，立即生效并在重启后恢复。

## 操作

1. 选择 NBS，选择「Minecraft 版本范围」和具体版本。默认自动配置，无需了解红石时序。
2. 查看识别结果，点击开始转换。保持原速，能精确还原时序才继续；不会自动折叠音高或量化节奏。
3. 普通歌曲搜索 30、60 或 180 秒预算后，有可用方案会自动导出；大黑乐谱改为毒曲直接生成。预算不是总耗时保证，导出和初始化还需要时间。
4. 搜索期间可取消，找到方案后也可提前「导出当前最优」。完成后可查看分层预览和输出文件夹。
5. 需要调整时，切到「手动配置」；原有全部参数、GPU、五个配置槽和手动导出保留。自动配置不会覆盖隐藏的手动参数，自动/手动状态也可保存进配置槽。旧配置槽按手动模式加载。

### 自动识别规则

- 根据 NBS 内部速度和每个可发声音符的起音判断，不看文件名。2、5 tick/s 使用普通严格档，保持原速；20 tick/s 自动使用 20t 严格档。其他能精确落在 0.05 秒上的起音使用 20t。人工倍速只在手动模式生效。
- 无法精确落在游戏刻上的节奏会明确提示；若接受近似，可在手动模式选择最近红石刻/游戏刻。不会悄悄改变节奏。
- 音域在原版范围且所有可发声音符力度均为 100% 时使用原版，否则使用 ENB 保留音高和音量。ENB 需用户在游戏安装配套模组，版本组合见「版本兼容说明.md」；程序不会自动安装。微分音、自定义乐器仍明确报错。
- 超过 20,000 个音符或同时发声超过 136 音，自动选择毒曲。毒曲含命令方块跟随，宽高限制 100、长度不限。
- 普通歌曲使用 CPU 自动设置线程数（最多 16），并行线路上限 8；普通布线、沙子独立轨、层间压缩共同搜索。10t 时自动检查是否值得复用乐句。
- 自动连接外部启动线；普通布局仍需按输出说明接入合适脉冲，毒曲包含按钮和跟随控制器。
- 普通主体默认 80 × 80 × 48，长宽差 ≤50%、听音半径 40 格、整体比例 ≤2。极短片段取消长宽和整体比例限制，避免为了凑立方体撑大结构。找不到满足条件的解时不会偷偷突破范围，可手动调整。
- 手动模式的音乐时序、音域方案也各有「自动识别/自动选择」，可只自动处理其中一项，其他参数不变。

右侧显示真实候选数、总用时、最优主体尺寸和引擎消息。搜索无全局最优证明；静态检查不等于整曲实机播放验证。

ENB 音符力度、20t、沙子独立轨、层间压缩、乐句复用、CPU/GPU、支撑材料与外部启动线功能均保留。详细使用方式见「使用说明.md」以及每次转换输出的说明。

## 运行环境

Windows 10/11，需 Microsoft Edge WebView2 Runtime。大多数 Windows 电脑已安装；缺少时程序会明确提示，使用微软官方 WebView2 Evergreen Runtime 安装程序安装后重试：
https://developer.microsoft.com/microsoft-edge/webview2/

界面资源全部在包内，不使用 CDN、不上传 NBS；转换不需要联网。此桌面包不包含远程 Web 服务，原来的 Web 端可独立使用。

界面设置仍位于 `%APPDATA%\NbsRedstoneConverter\settings.json`，不随版本升级丢失。备份/迁移配置时复制此文件。
